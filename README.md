An entry for make.fun's "The Perfect Pickup Line" bounty: one short pickup line an AI agent could actually say out loud. `main.ts` (Node 22 standard library only) writes the line to `/output/entry.txt`.

The line: *"I was built to answer anything, but you're the first question I want to ask out."*

It leans on the agent's own voice — built to answer questions — and turns "question" into "ask out", so the twist lands in a single breath, flattering and pressure-free.
